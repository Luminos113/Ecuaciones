Método de Euler y Separación de Variables

En este proyecto se trabaja con la ecuación diferencial:

dy/dt = y

con la condición inicial:

y(0) = 1

La solución exacta por separación de variables es:

y(t) = e^t

También se utilizó el método de Euler con un paso de:

h = 0.2

El programa compara los valores obtenidos con Euler contra la solución exacta y muestra el error en cada paso.

Tecnología utilizada:
Python
